# Dance Pulse

Telegram-бот, который перед каждым занятием спрашивает учеников группы, придут ли они, и даёт преподавателю готовую сводку. Закрывает одну конкретную боль — перекличку в общих чатах вручную.

Это **не CRM**. Учёт абонементов, баланса, расписания залов и платежей — у школ для этого уже есть коробочные продукты (AppEvent, Impulse CRM и т.п.). Бот сознательно делает только то, чего эти CRM не делают: проактивный двусторонний опрос посещаемости.

## Что работает сейчас (Фазы 1–3)

- Преподаватель: `/start`, `/newgroup`, `/groups`, `/today`, `/stats`
- Создание группы: название → дни недели → время; бот выдаёт ссылку-приглашение
- Ученик переходит по ссылке `t.me/<bot>?start=join_<code>` и записывается в группу
- Карточка группы: список учеников, ссылка-приглашение, удаление
- **Опросы посещаемости:** за `lead_hours` до занятия бот сам рассылает ученикам «придёшь?» с кнопками да/нет, собирает ответы
- `/today` — сводка по ближайшим занятиям: кто придёт, кто нет, кто не ответил
- **Авто-сводка:** на середине окна опроса бот сам присылает преподавателю промежуточные итоги
- `/stats` — посещаемость по группам за последние занятия (по ответам на опрос)

Фидбек-опросы после занятия — отложены (потребность не подтверждена).

## Архитектура

```
┌──────────────┐   polling    ┌──────────────────────┐
│ Telegram     │ ───────────▶ │  aiogram 3           │
│ препод+учен  │ ◀── reply ── │  handlers            │
└──────────────┘              │  (teacher / student) │
                              └──────────┬───────────┘
                  ┌──────────────────────┼───────────┐
                  ▼                      ▼            │
          ┌──────────────┐      ┌──────────────┐      │
          │ APScheduler  │      │  SQLAlchemy  │◀─────┘
          │ tick / 15мин │      │   (SQLite)   │
          └──────────────┘      └──────────────┘
```

Бот и scheduler — в одном процессе ([app/main.py](app/main.py)). Бизнес-логика в [app/services/](app/services/) переиспользуется хэндлерами и (в Фазе 2) scheduler'ом.

## Требования

- Python 3.12+
- Telegram-бот-токен от [@BotFather](https://t.me/BotFather)

База данных — SQLite, отдельный сервер не нужен; файл создаётся автоматически.

## Запуск

```powershell
# 1. Окружение и зависимости
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e ".[dev]"

# 2. Настроить .env
copy .env.example .env
# вписать BOT_TOKEN от @BotFather

# 3. Запустить
python -m app.main
```

SQLite-файл (`dance.sqlite3`) создаётся при первом старте.

Проверка с двух Telegram-аккаунтов:
1. С аккаунта-преподавателя: `/start` → `/newgroup` → пройти мастер → скопировать ссылку-приглашение.
2. С аккаунта-ученика: перейти по ссылке.
3. Снова препод: `/groups` → выбрать группу → «Ученики» — ученик в списке.
4. Опрос: в `/newgroup` задай время занятия так, чтобы до него осталось меньше `DEFAULT_LEAD_HOURS` часов — в течение 15 минут бот разошлёт опрос ученику. Ответь кнопкой, проверь `/today` у препода.

## Решения дизайна

- **SQLite, не Postgres.** Утилите не нужна инфраструктура — один файл.
- **Управление в боте, без веб-панели.** Преподаватель в телефоне.
- **Polling, не webhook.** Не нужен публичный URL.
- **Не дублирует школьную CRM.** Бот знает учеников только чтобы слать им опрос, он не «система записи».
