# Web-прокликивание через Playwright MCP

Живой клик-тест бота: Claude открывает **web.telegram.org** в Chromium (Playwright MCP),
кликает реальные кнопки `@dancepulsebot` и снимает скриншоты. Это **активный** путь e2e
(Telethon в `../live/` заброшен — api_id блокируется регионом на my.telegram.org).

## Конфигурация (готова)

- MCP-сервер `playwright` прописан в [`../../.mcp.json`](../../.mcp.json) →
  `@playwright/mcp` с конфигом [`mcp-config.json`](mcp-config.json).
- Браузер: **бандл-Chromium** (не системный Chrome), отдельный профиль
  `e2e/web/.profile` (в .gitignore), локаль форсирована `en-US`, headed.
- В профиль залогинены **два аккаунта** (переключение по URL `?account=N`):
  - **acc#1 = dev** — имя «Paul Lake», tg id `6664457053`;
  - **acc#2 = препод/админ** — владелец группы «Бачата · ур.1».
  Логины персистентны (переживают перезапуск) — повторно входить не нужно.

## ⚠️ Как продолжить (состояние на 2026-06-27, пауза)

1. **Запусти бота** — без него клики уходят в никуда (polling):
   ```powershell
   python -m app.main   # лог в run-bot.log; на паузе он остановлен
   ```
2. Убедись, что Playwright-MCP **connected**: `/mcp` (грузится при старте Claude Code).
3. Скажи Claude, какой сценарий гонять (см. ниже) — он сам водит браузер и шлёт скриншоты.

**Что уже проверено вживую (работает):** `/start`, карточка группы, «Пригласить»
(QR + ссылка `?start=join__…`), полный **онбординг ученика** (acc#1 зашёл по ссылке →
имя → пол → запись в группу) и **уведомление преподу** (acc#2). Reply-кнопки нижнего
меню «нажимаются» отправкой их текста, inline — обычным кликом (callback).

**Тестовые данные:** Paul Lake (acc#1) записан в «Бачата · ур.1».
Снести фейков — `python -m scripts.purge_fakes` (сперва `--dry-run`).

**Следующие сценарии (выбор за пользователем):**
- Опрос «придёшь?» → клик Приду/Не приду (триггер: `scripts/trigger_poll` или сдвиг времени занятия).
- Автосбор саппортов (`/pool`, picker, режимы, живой баланс-бар).
- Пост-занятие: «Отметить посещаемость» (toggle ☐→✅→❌, walk-in).
- Мастер создания группы (aiogram-dialog, навигация «Назад»).

## Полезные селекторы (Web K)

- Поле ввода чата бота: `div.input-message-input[data-peer-id="8956679400"]` (8956679400 = id бота).
- Inline-кнопки: `button.reply-markup-button:has-text("<текст>")`.
- Точную deep-ссылку из сообщения тащить через `browser_evaluate` (а не глазами — подчёркивания).

## Тонкости

- **Один Chromium на профиль** — если откроешь системный Chrome на этом же `--user-data-dir`,
  будет лок. У нас отдельный профиль, так что системный Chrome можно не закрывать.
- Сбросить web-сессию — удали `e2e/web/.profile/`.
- Артефакты Playwright (`.playwright-mcp/`, скриншоты) — в .gitignore.
